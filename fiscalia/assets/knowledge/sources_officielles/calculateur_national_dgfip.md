# Code source du calculateur national DGFiP

## Synthèse
Le code source du calculateur national d'impôt sur le revenu publié par la DGFiP formalise la logique de calcul utilisée pour la campagne officielle. Cette source n'est pas une base légale en elle-même, mais elle constitue une implémentation officielle de référence pour les calculs.

## Statut officiel
- Autorité éditoriale : Direction générale des finances publiques (DGFiP).
- Niveau de fiabilité : source officielle pour la logique de calcul publiée.
- Usage RAG prioritaire : validation d'algorithmes, paramètres de calcul et comportement des simulateurs.

## Corpus fiscal couvert
- Paramètres et règles de calcul de l'impôt sur le revenu.
- Implémentation de la campagne annuelle.
- Cas techniques utiles pour rapprocher un simulateur applicatif du calculateur officiel.

## Accès technique
- Point d'entrée : dépôt GitHub public officiel.
- URL officielle : https://github.com/dgfip/calculette-impots-m-source-code
- Format attendu : fichiers sources, paramètres, logique de calcul versionnée.
- Identifiants utiles : millésime, modules de calcul, paramètres de campagne.

## Recommandations d'ingestion
- Indexer la documentation du dépôt et les fichiers décrivant les paramètres de calcul.
- Distinguer clairement la logique algorithmique du texte légal.
- Associer chaque règle à sa campagne fiscale et, si possible, à la référence légale correspondante.
- Utiliser cette source en complément, pas en remplacement de la loi et de la doctrine.

## Priorité RAG
- À utiliser pour expliquer un calcul ou vérifier un comportement algorithmique.
- À signaler comme implémentation officielle plutôt que comme texte normatif.
- À croiser avec CGI, lois de finances et BOFiP pour la justification juridique.
