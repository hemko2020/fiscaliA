# AGENTS.md - FiscalIA

## Project Context

FiscalIA est une application Flutter de gestion fiscale pour les utilisateurs francophones.

## Regles

- Preferer les modeles locales (Ollama) pour la confidentialite
- Utiliser des noms en francais pour les variables et fonctions liees au domaine fiscal
- Interpreter les questions fiscales en considerant la legislation francaise
- Documenter les calcules fiscaux avec des referenceslegislatives

## Outils Preferes

- Utiliser `context7` pour rechercher la documentation Flutter
- Utiliser `gh_grep` pour des exemples de code
- Utiliser `sentry` pour le debugging en production
